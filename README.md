# Hi, I'm Pastalikek65 👋

Systems-programming hobbyist who rebuilds infrastructure primitives from scratch in Go, Rust, and C++ to understand how they actually work.

## 🧪 What I build

I learn best by reimplementing core systems — zero external dependencies whenever possible.

| Project | What it is |
|---|---|
| [termtunnel](https://github.com/Pastalikek65/termtunnel) | P2P TCP/HTTP tunnel over WebRTC with Noise end-to-end encryption — an ngrok alternative for Termux |
| [goredis](https://github.com/Pastalikek65/goredis) | Redis-compatible key-value store from scratch — RESP protocol, sharded concurrency, RDB/AOF persistence, Pub/Sub |
| [gotorrent](https://github.com/Pastalikek65/gotorrent) | BitTorrent client from scratch — bencode, HTTP tracker w/ BEP 12 failover, peer wire protocol, verified download, resume |
| [cronping](https://github.com/Pastalikek65/cronping) | Tiny low-memory cron daemon that alerts (Telegram/Discord/ntfy/webhook) when a scheduled job fails, with durable retry queue |
| [sqlite-backups](https://github.com/Pastalikek65/sqlite-backups) | Consistent hot-backups of live SQLite: Online Backup API, LZ4/gzip, cron + retention, local/S3 |
| [edgewasm-runtime](https://github.com/Pastalikek65/edgewasm-runtime) | A from-scratch WASM runtime in Rust |
